Usage

Load the registry once. It fetches providers lazily, so nothing downloads until you ask for an icon.

local Icons = loadstring(game:HttpGet())()

Icons.SetProvider("tabler")                 -- every later lookup uses tabler
local a = Icons.GetAsset("moon")
local b = Icons.GetAsset("moon", "lucide")  -- or pick per lookup

What you get back

Url
The spritesheet. Cached to disk when the executor can, otherwise an uploaded Roblox asset.
ImageRectSize
ImageRectOffset
Where the icon sits on that sheet. Assign all three to an ImageLabel.
FontFace
Text
The same icon as a font glyph, crisp at any TextSize up to 100. nil when fonts are unavailable.

Icon names follow each set's own convention, so moon in Lucide is weather-moon-24-regular in Fluent. Renamed icons keep working through aliases.
